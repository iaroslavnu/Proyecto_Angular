🃏 Buscador de Cartas Pokémon

Aplicación web desarrollada con Angular que consume una API REST de cartas Pokémon y permite buscar y filtrar cartas por nombre.

Mostrar imagen

✨ Funcionalidades
Búsqueda y filtrado de cartas Pokémon por nombre.
Listado de resultados obtenidos desde la API.
Vista de detalle: al hacer clic en una carta se muestra ampliada, con su descripción, estadísticas y precio.
Top 10 de las cartas más caras.
🛠️ Tecnologías
Capa	Tecnología
Frontend	Angular, TypeScript, HTML5, CSS3
Consumo de datos	API REST con HttpClient 
API	Pokémon TCG API
Control de versiones	Git / GitHub
🔌 API utilizada

La aplicación consume la API Pokemon TCG API. Se realizan peticiones HTTP para obtener las cartas y se filtran por el nombre introducido por el usuario.
